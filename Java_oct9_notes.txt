JDK(Java Development Kit) is a software that holds all the tools to run a java program. 
JDK has Development tools and JRE
Inside JRE it has JVM and Libraries set
=> Development tools : Javadoc, debugger, Compiler
The purpose of Javadoc - to automatically generate standardized, professional API documentation in HTML format directly from Java source code.
Debugger - we will use breakpoints and go through the code to see what the data holds
Java Compiler(javac): It is a part of development tools. It checks the syntax (eg: types of brackets, closing of line of code (;),keywords ..etc)

javac command tells the compiler to compile specified java file.
eg: javac Employee.java

Compiler Uses: 
=> It helps us to detect syntactical errors and we can fix them. and then generates .class which has bytecode.
=> this byte is platform independent. It means i can be execute on any platform.

.class files can be archived together as a package or jar file and can be released into production.
